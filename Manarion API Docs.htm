Documentation

Endpoints

  • GET https://api.manarion.com/players/{id|name} – Fetches public player profile info.
  • GET https://api.manarion.com/guilds?gameMode=0 – Fetches the list of all guilds.
  • GET https://api.manarion.com/guilds/{id}?apikey= – Fetches guild details. The API key is visible to the guild leader on the guild info page.
  • GET https://api.manarion.com/leaderboards/{type}?page=1&gameMode=0 – Fetches a leaderboard page. Optional guild={id} parameter
  • GET https://api.manarion.com/market – Fetches market prices
